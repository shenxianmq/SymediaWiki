## 三、配置教程

### 3.1 docker 命令配置

- 如 docker-compose 命令，增加变量和路径映射

  - 路径映射增加：

  ```shell
    /vol1/1000/DATA/AppData/symedia/playwright:/symedia/.cache/ms-playwright
  ```

  - 环境变量增加：
    ```shell
    COVER_MAKER=true
    ```

```yaml
version: "3.8"

services:
  symedia:
  image: shenxianmq/symedia:latest
  container_name: symedia
  restart: always
  ports:
    - "8095:8095"
  volumes:
    - /volume1/CloudNAS/:/CloudNAS:rslave
    - /volume1/media:/media
    - /vol1/1000/DATA/AppData/symedia/config:/app/config
    - /vol1/1000/DATA/AppData/symedia/playwright:/symedia/.cache/ms-playwright #本次添加
    - /var/run/docker.sock:/var/run/docker.sock:ro
  environment:
    - TZ=Asia/Shanghai
    - LICENSE_KEY=eyj89j9fjrfkr9fpi
    - COVER_MARKER=True #本次添加
```

### 3.2 下载封面图

- 通过油猴插件，下载 emby 封面海报
  - 根据插件的模式，下载对应张数
  - 如果需要排序，图片文件数字命名（例如 1.jpg、2.jpg）

![](https://images.symedia.top/2025/05/05/20250505102126_5def6cde.png)

### 3.3 封面功能配置

- 功能入口：插件 ➡️ 动态封面
- 功能配置：如图
  - 上传图片: 添加图片后点击上传
  - 生成预览：静态预览图
  - 生成封面：点击后，后台会自动生成一张

![](https://images.symedia.top/2025/05/05/20250505115735_82b989e0.png)

- 自定义字体: 添加字体映射目录，将字体上传到该目录中的 Chinese,English 文件夹中，分别对应着中文字体和英文字体

```shell
/volume1/docker/symedia/fonts:/app/static/fonts
```

![](https://images.symedia.top/2025/05/05/20250505115211_93e4febf.png)

- 英文如何换行：加入<br>标签即可

![](https://images.symedia.top/2025/05/05/20250505152801_2f9be2cb.png)

![](https://images.symedia.top/2025/05/05/20250505152809_2435abc7.png)

- 下载链接：如果需要下载链接，请在全局设置中；设置 SA 的域名+端口号

- 生成后的封面会出现在:/app/config/Cover 目录中
