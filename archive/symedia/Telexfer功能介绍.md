# 🚀 TeleXfer 功能介绍

## 📱 核心功能

### 🤖 Bot 转存

- **自动转存**：Telegram Bot 自动识别并转存分享链接到云盘
- **多平台支持**：支持 115、123、189、夸克等主流云盘
- **智能归档**：自动匹配归档规则，支持自定义目录结构
- **离线下载**：115 网盘支持离线下载功能

### 📨 消息转发

- **批量转发**：支持多源聊天到多目标聊天的批量转发
- **智能过滤**：关键词过滤、文件类型过滤、时间范围过滤
- **实时监控**：自动监控源聊天，发现新消息立即转发
- **灵活配置**：支持包含/排除关键词、正则表达式匹配

### ☁️ 云盘转存

- **多账号管理**：支持多个云盘账号同时管理
- **自动转存**：Telegram 消息中的分享链接自动转存到云盘
- **目录管理**：支持自定义转存目录，灵活组织文件结构
- **状态监控**：实时查看转存任务状态和进度

### ⏰ 定时任务

- **定时发送**：支持定时发送消息到指定聊天
- **灵活调度**：支持每日定时、自定义时间格式
- **批量操作**：可配置多个定时任务同时运行

### 📂 文件归档

- **多种方式**：支持移动、复制、硬链接、软链接四种归档方式
- **智能匹配**：自动匹配归档规则，支持正则表达式
- **空间优化**：硬链接和软链接不占用额外存储空间
- **实时监控**：支持文件系统监控，新文件自动归档

### 📥 内容下载

- **抖音下载**：支持抖音视频下载
- **B 站下载**：支持 B 站视频和用户主页内容下载
- **批量下载**：支持批量下载任务管理

### 🔍 消息索引

- **全文搜索**：支持消息内容全文搜索
- **快速检索**：快速定位历史消息
- **数据管理**：消息数据索引和管理

### 📝 日志管理

- **详细日志**：系统运行日志详细记录
- **分类查看**：支持按类型、时间筛选日志
- **实时更新**：日志实时更新，方便问题排查

### ⚙️ 系统设置

- **灵活配置**：丰富的系统配置选项
- **主题切换**：支持明暗主题切换

## 🎯 适用场景

- 📦 **资源管理**：Telegram 群组资源自动归档整理
- 🔄 **内容同步**：多频道内容同步和转发
- 📥 **批量下载**：批量下载视频和媒体内容
